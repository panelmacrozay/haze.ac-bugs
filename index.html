active bugs
BUG-001
Bug
FPS Changer — Black Screen / Stretch
Using the FPS changer and loading into a game causes issues at both extremes. Lowering FPS locks the screen black. Maxing it out stretches the game beyond the viewport — you can't see the HUD or gameplay area.
BUG-002
Bug
Aimbot — Bow Projectiles Not Tracking
Aimbot fails to account for projectile arc on bows. Prediction is off — shots consistently miss moving targets. Bone target set to head worsens it.
Workaround Switch aimbot bone target to spine — improves projectile leading accuracy significantly.
BUG-003
Bug
Silent Aim — Not Functioning
Silent aim is currently broken across all tested configs. Shots register at cursor position rather than snapping to target silently. No workaround confirmed yet.
BUG-004
Bug
Overlay — Random Crashes
The overlay process exits unexpectedly at irregular intervals during gameplay. No reproducible trigger identified — appears timing-based or memory-pressure related.
BUG-005
Bug
Aimbot — Stops Working Randomly
Aimbot drops out mid-session. Root cause: the remove-layer call desynchronizes the aimbot hook unexpectedly, causing it to silently fail without crashing.
Workaround Kill Haze Loader in Task Manager → Alt+F4 Rust → Reopen loader → Launch Rust → Launch cheat. Aimbot resumes normally.
BUG-006
Bug
ESP — Entity Draw Freezes at Count
ESP stops rendering new entities after hitting a specific entity count. The draw list gets stuck — existing boxes persist but new players entering range don't appear.
Workaround Same reset loop as BUG-005: Task Manager → kill loader → Alt+F4 Rust → relaunch. ESP refreshes on next load.
fatal issues
FATAL-001
Fatal
Driver Overload → BSOD on Repeated Load
Loading the driver too many times in a session triggers Windows kernel integrity checks. Results in a hard system crash — blue screen of death.
CRITICAL_STRUCTURE_CORRUPTION — 0x00000109
FATAL-002
Fatal
Driver — Crashes System After Extended Session
The driver destabilizes after a certain runtime period — likely a memory leak or handle exhaustion in kernel space. PC hard-crashes with no consistent error code. Session time before crash varies per machine.
